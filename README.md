# ✨ SmartEarn AI - Premium Creator & ID Marketplace

Welcome to the **SmartEarn AI Marketplace**! This is a professional, highly secure platform designed for creators and gamers to buy and sell verified social media and gaming accounts.

## 🚀 Key Features
* **Secure ID Escrow System:** 100% safe transactions verified manually by admins via WhatsApp.
* **Premium Marketplace:** Users can browse and buy accounts (BGMI, Free Fire, Instagram, YouTube) seamlessly.
* **7-Image Full-Screen Gallery:** Sellers can upload multiple screenshots which auto-compress for fast loading.
* **AI Creator Tools:** Free built-in tools for Video Generation, Sponsorship Pitches, Reel Ideas, Scripts, and Hooks.
* **Admin Dashboard:** A password-protected (`swasti@29`) control center to approve/reject IDs and verify UPI UTR payments.

## 🛠️ Tech Stack
* HTML5, CSS3 (Glassmorphism & Bento-grid UI)
* Vanilla JavaScript (ES6+)
* LocalStorage (for data persistence)
* FormSubmit API (for Email Notifications)

## 🔒 Security
* Advanced anti-password suggestion hacks (`autocomplete="new-password"`).
* Unique Timestamp ID generation for bug-free database management.
